\# GIV-PESADOS



\*\*Gestor de Inventario y Ventas de Repuestos Pesados\*\*



GIV-PESADOS es un sistema de escritorio desarrollado en Java Swing (NetBeans) y MySQL, diseñado para gestionar de forma integral el inventario y las ventas de repuestos para vehículos de carga pesada y transporte colectivo, incluyendo buses, camiones, rastras y maquinaria pesada.



El proyecto combina un sistema de control de inventario con un Punto de Venta (POS), permitiendo automatizar procesos clave como el registro de productos, control de existencias, gestión de categorías, marcas y proveedores, generación de facturas y seguimiento detallado de cada transacción.



\## Características Principales



\* Gestión de repuestos y productos.

\* Control de inventario y stock en tiempo real.

\* Administración de categorías, marcas y proveedores.

\* Módulo de Punto de Venta (POS).

\* Generación e impresión de facturas.

\* Registro de usuarios y roles.

\* Trazabilidad de ventas mediante identificación del vendedor responsable.

\* Consultas y reportes de inventario y ventas.

\* Interfaz gráfica desarrollada con Java Swing.



\## Tecnologías Utilizadas



\* Java Swing

\* Apache NetBeans

\* MySQL

\* SQLyog



\## Objetivo del Proyecto



El objetivo principal de GIV-PESADOS es ofrecer una solución robusta para la administración de inventario y ventas en empresas dedicadas a la comercialización de repuestos para transporte pesado, mejorando la eficiencia operativa, reduciendo errores manuales y garantizando un control preciso de cada movimiento de inventario y cada venta realizada.



\## Alcance



El sistema está enfocado en cubrir las necesidades esenciales de un negocio de repuestos, desde la entrada y salida de productos hasta la facturación y el seguimiento de los vendedores, proporcionando una herramienta práctica y escalable para la gestión diaria del negocio.
